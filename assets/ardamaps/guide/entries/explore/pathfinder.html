The Pathfinder is a great way of exploring Middle-earth from the perspective of the Fellowship.

Configuration

When holding it, right click to select which character's path you'd like to follow.


  • Select a Path to Follow lists the available character paths to follow
  • Select a Chapter lists the chapters available for the given Path
  • Clicking Return to Path will take you to the nearest point of the path you're currently following.
  • Clicking Return to Chapter Start will take you to the beginning of the selected chapter
  • Show Proximity Text enables the display of book excerpts and quotes along the path
  • Text Scroll Speed adjusts the speed at which the proximity text displays
  • Show Chapter Titles enables the display of the chapter title along the path
  • Chapter Titles Duration adjusts the speed at which the title disappears
  • Journal opens a list of the previous visited waypoints along the path

Journal


The Journal displays a list of the last visited waypoints on the path is a descending ordered (recent to eldest). Clicking the teleport button will teleport you to the given entry or chapter start.
