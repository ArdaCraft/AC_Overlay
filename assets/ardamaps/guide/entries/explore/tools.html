Warps

We have a single enormous map which you can explore on foot, but to get to locations quickly you can use /warp.
To use this chatcommand, type /warp and then the location name. For example, /warp Rivendell will take you to Rivendell.


Night Vision

Use /nv to enable or disable night vision.


Time and Weather

To change the time, press G. Set 'World Time' to OFF and then select Noon, Midnight, Sunrise or Sunset (you can also type a custom number). 'Moving Time' is also available in the bottom right, which sets the time scaled to our map.
To change the weather, type /clientweather rain or /clientweather clear.
